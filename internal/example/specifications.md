# Спецификация языка программирования miniGoOnGo

## 1. Введение

miniGoOnGo — это минималистичный императивный язык программирования, предназначенный для изучения принципов построения языков программирования, лексического и синтаксического анализа, а также разработки интерпретаторов.

Язык использует синтаксис, сочетающий элементы Go, Java и C-подобных языков. Программа на miniGoOnGo состоит из одного файла с исходным кодом и содержит единственную точку входа — функцию `main`.

Основные возможности языка:

1. Строгая статическая типизация.
2. Объявление переменных с явным указанием типа.
3. Арифметические операции над числами.
4. Операции сравнения и логические операции.
5. Условные конструкции `if` и `else`.
6. Циклическая конструкция `while`.
7. Вывод информации с помощью встроенной функции `print`.
8. Объединение строк с помощью оператора `+`.
9. Одномерные массивы: создание, чтение и запись элементов, поле `length`.
10. Структуры (записи): именованные наборы полей, доступ через `.`.

## 2. Система типов

Язык miniGoOnGo поддерживает следующие типы данных:

- `int` — целочисленный тип данных (32-битный знаковый).
- `float` — тип данных для хранения чисел с плавающей точкой (64-битный).
- `string` — строковый тип данных.
- `bool` — логический тип данных.
- `T[]` — одномерный массив элементов типа `T`, где `T` — один из базовых типов (`int`, `float`, `string`, `bool`) или имя структуры.
- `S` — тип структуры, где `S` — имя структуры, объявленной в программе.

Логический тип `bool` принимает два значения: `true` и `false`.

Каждая переменная должна иметь явно указанный тип и начальное значение при объявлении.

Пример:

```go
struct Point {
    int x;
    int y;
}

string name = "Alexander";
int age = 22;
float height = 1.80;
bool isStudent = true;
int[] scores = new int[10];
Point origin = Point{0, 0};
```

## 3. Лексика

### 3.1. Идентификаторы

1. Идентификатор представляет собой последовательность букв английского алфавита, цифр и символов подчёркивания `_`.
2. Идентификатор должен начинаться с буквы английского алфавита или символа подчёркивания.
3. Идентификатор не может начинаться с цифры.
4. Регистр символов имеет значение.
5. Идентификаторы не могут совпадать с ключевыми словами языка.

Примеры допустимых идентификаторов:

```text
name
age
userName
counter
_isActive
value123
```

Примеры недопустимых идентификаторов:

```text
123name
user-name
my value
```

### 3.2. Ключевые слова

Ключевые слова зарезервированы языком и не могут использоваться в качестве идентификаторов. Регистр ключевых слов имеет значение: они записаны в нижнем регистре и должны использоваться именно в таком виде (`if` — ключевое слово, `If` — идентификатор).

Список ключевых слов:

```text
func
main
int
float
string
bool
true
false
if
else
while
print
new
struct
```

### 3.3. Числовые литералы

1. Целочисленные литералы представляют собой последовательность десятичных цифр.
2. Вещественные литералы содержат целую и дробную части, разделённые точкой.
3. Числовые литералы не содержат знак. Отрицательные значения формируются с помощью унарного оператора `-`.
4. Целочисленный литерал не может начинаться с нуля, если содержит более одной цифры.
5. Вещественный литерал должен содержать хотя бы одну цифру до и после десятичной точки.

Примеры:

```text
0
1
22
1000
1.80
3.14
0.5
```

### 3.4. Строковые литералы

1. Строковые литералы заключаются в двойные кавычки `"`.
2. Строка может содержать буквы, цифры, пробелы и другие допустимые символы.
3. Внутри строки не допускается необработанный символ перевода строки.
4. Для представления специальных символов используются escape-последовательности.

Поддерживаемые escape-последовательности:

| Последовательность | Значение |
|---|---|
| `\"` | Двойная кавычка |
| `\\` | Обратная косая черта |
| `\n` | Перевод строки |
| `\t` | Табуляция |
| `\r` | Возврат каретки |

Пример:

```go
string message = "Hello, world!";
string text = "First line\nSecond line";
```

### 3.5. Логические литералы

Язык поддерживает два логических литерала:

- `true` — истина.
- `false` — ложь.

### 3.6. Комментарии

В языке поддерживаются однострочные комментарии.

1. Однострочный комментарий начинается с последовательности символов `//`.
2. Комментарий продолжается до конца текущей строки.
3. Комментарии игнорируются при лексическом и синтаксическом анализе программы.

Пример:

```go
// Это комментарий
int age = 22; // Комментарий после инструкции
```

Многострочные комментарии в текущей версии языка не поддерживаются.

### 3.7. Пробельные символы

Пробельные символы могут располагаться между лексемами и игнорируются при лексическом анализе.

К пробельным символам относятся:

| Символ | Название |
|---|---|
| SP | Пробел |
| HT | Горизонтальная табуляция |
| LF | Перевод строки |
| CR | Возврат каретки |

### 3.8. Операторы

Список операторов языка:

| Оператор | Назначение |
|---|---|
| `=` | Присваивание |
| `+` | Сложение или объединение строк |
| `-` | Вычитание |
| `*` | Умножение |
| `/` | Деление |
| `%` | Остаток от деления |
| `==` | Равно |
| `!=` | Не равно |
| `<` | Меньше |
| `>` | Больше |
| `<=` | Меньше или равно |
| `>=` | Больше или равно |
| `&&` | Логическое И |
| `||` | Логическое ИЛИ |
| `!` | Логическое НЕ |

### 3.9. Прочие лексемы

К прочим лексемам относятся разделители и специальные символы:

```text
( )
{ }
[ ]
;
,
.
```

## 4. Синтаксис

Синтаксис языка описывается с помощью EBNF в соответствии с нотацией ISO/IEC 14977:1996.

Допускаются только программы, которые сводятся к нетерминалу `program`.

### 4.1. Программа

Программа состоит из нуля или более объявлений структур, за которыми следует функция `main`.

```ebnf
program = { struct_declaration }, main_function, end_of_file ;

main_function = "func", "main", "(", ")", block ;

struct_declaration = "struct", identifier, "{", { field_declaration }, "}" ;

field_declaration = type, identifier, ";" ;
```

### 4.2. Блоки кода

Блок кода представляет собой последовательность инструкций, заключённых в фигурные скобки.

```ebnf
block = "{", { statement }, "}" ;
```

### 4.3. Инструкции

Инструкция представляет собой объявление переменной, присваивание, вызов функции вывода, условную конструкцию, цикл или вложенный блок.

```ebnf
statement = variable_declaration
          | assignment_statement
          | print_statement
          | if_statement
          | while_statement
          | block ;
```

### 4.4. Объявление переменных

Объявление переменной содержит тип, идентификатор и выражение, определяющее начальное значение переменной.

```ebnf
variable_declaration = type, identifier, "=", expression, ";" ;

type = "int"
     | "float"
     | "string"
     | "bool"
     | identifier
     | "int" "[" "]"
     | "float" "[" "]"
     | "string" "[" "]"
     | "bool" "[" "]"
     | identifier "[" "]" ;
```

Здесь `identifier` в позиции типа обозначает имя структуры, объявленной в программе. Массив структур записывается как `S[]`.

Примеры:

```go
int age = 22;
float height = 1.80;
string name = "Alexander";
bool isStudent = true;
int[] scores = new int[10];
Point origin = Point{0, 0};
Point[] path = new Point[5];
```

### 4.5. Присваивание

Присваивание позволяет изменить значение ранее объявленной переменной, элемента массива или поля структуры.

```ebnf
assignment_statement = assignable, "=", expression, ";" ;

assignable = identifier
           | index_access_expression
           | field_access_expression ;
```

Примеры:

```go
counter = counter + 1;
scores[0] = 100;
point.x = 5;
```

### 4.6. Вывод информации

Для вывода информации используется встроенная функция `print`, принимающая одно выражение.

```ebnf
print_statement = "print", "(", expression, ")", ";" ;
```

Примеры:

```go
print("Hello, world!");
print(100);
print(true);
```

### 4.7. Условная конструкция

Условная конструкция `if` позволяет выполнить блок кода в зависимости от результата логического выражения.

Необязательная часть `else` определяет блок, выполняемый в случае ложности условия.

```ebnf
if_statement = "if", "(", expression, ")", block,
               [ "else", block ] ;
```

Пример:

```go
if (age >= 18 && isStudent) {
    print("Adult student");
} else {
    print("Other");
}
```

### 4.8. Циклическая конструкция

Цикл `while` выполняет блок кода до тех пор, пока условие остаётся истинным.

```ebnf
while_statement = "while", "(", expression, ")", block ;
```

Пример:

```go
while (counter < 5) {
    print(counter);
    counter = counter + 1;
}
```

### 4.9. Выражения

Выражения используются для вычисления значений, которые могут быть присвоены переменным, переданы в функцию `print` или использованы в условиях.

Общее правило выражения:

```ebnf
expression = logical_or_expression ;
```

#### Логическое ИЛИ

```ebnf
logical_or_expression =
    logical_and_expression,
    { "||", logical_and_expression } ;
```

#### Логическое И

```ebnf
logical_and_expression =
    equality_expression,
    { "&&", equality_expression } ;
```

#### Операции равенства и неравенства

```ebnf
equality_expression =
    relational_expression,
    { ( "==" | "!=" ), relational_expression } ;
```

#### Операции сравнения

```ebnf
relational_expression =
    additive_expression,
    { ( "<" | ">" | "<=" | ">=" ), additive_expression } ;
```

#### Сложение и вычитание

```ebnf
additive_expression =
    multiplicative_expression,
    { ( "+" | "-" ), multiplicative_expression } ;
```

#### Умножение, деление и остаток от деления

```ebnf
multiplicative_expression =
    unary_expression,
    { ( "*" | "/" | "%" ), unary_expression } ;
```

#### Унарные операции

```ebnf
unary_expression = primary_expression
                 | "-", unary_expression
                 | "!", unary_expression ;
```

#### Основные выражения

```ebnf
primary_expression = integer_literal
                    | float_literal
                    | string_literal
                    | boolean_literal
                    | variable_access
                    | array_literal
                    | index_access_expression
                    | field_access_expression
                    | new_expression
                    | "(", expression, ")" ;

variable_access = identifier ;

boolean_literal = "true" | "false" ;

array_literal = "{", [ expression, { ",", expression } ], "}" ;

index_access_expression = variable_access, "[", expression, "]" ;

field_access_expression = variable_access, ".", identifier ;

new_expression = "new", type, "[", expression, "]" ;
```

### 4.10. Лексические элементы

Следующие элементы определяются в разделе «Лексика»:

```ebnf
identifier = ? определён в лексике ? ;

integer_literal = ? определён в лексике ? ;

float_literal = ? определён в лексике ? ;

string_literal = ? определён в лексике ? ;

end_of_file = ? признак конца файла ? ;
```

## 5. Семантические правила

### 5.1. Типизация

1. Язык использует строгую статическую типизацию.
2. Каждая переменная должна иметь явно указанный тип.
3. Тип переменной определяется при её объявлении и не может изменяться в дальнейшем.
4. Значение, присваиваемое переменной, должно соответствовать её типу.
5. Неявное преобразование типов не поддерживается.
6. Использование переменной до её объявления запрещено.
7. Повторное объявление переменной с тем же именем в одной области видимости запрещено.

### 5.2. Литералы

1. Целочисленные литералы имеют тип `int`.
2. Вещественные литералы имеют тип `float`.
3. Строковые литералы имеют тип `string`.
4. Логические литералы `true` и `false` имеют тип `bool`.

### 5.3. Арифметические операции

Для числовых типов `int` и `float` поддерживаются следующие операции:

- сложение: `+`;
- вычитание: `-`;
- умножение: `*`;
- деление: `/`;
- унарный минус: `-`.

Операнды арифметических операций должны иметь одинаковый числовой тип. Результат операции имеет тот же тип, что и операнды.

Операция остатка от деления `%` поддерживается только для значений типа `int`.

Деление на ноль и вычисление остатка от деления на ноль приводят к ошибке выполнения программы.

### 5.4. Операции со строками

1. Для строк поддерживается операция объединения с помощью оператора `+`.
2. Операция принимает два значения типа `string` и возвращает новое строковое значение.
3. Объединение строк с числами и логическими значениями без явного преобразования типов не допускается.

Пример:

```go
string firstName = "Alexander";
string lastName = "Rusanov";
string fullName = firstName + " " + lastName;
```

### 5.5. Операции сравнения

Поддерживаются следующие операции сравнения:

- `==` — равно;
- `!=` — не равно;
- `<` — меньше;
- `>` — больше;
- `<=` — меньше или равно;
- `>=` — больше или равно.

Операции сравнения возвращают значение типа `bool`.

1. Для числовых типов поддерживаются все перечисленные операции.
2. Для строк поддерживаются операции равенства и неравенства.
3. Для логических значений поддерживаются операции равенства и неравенства.
4. Операнды должны иметь одинаковые типы.
5. Для ссылок на массивы и структуры поддерживаются операции равенства и неравенства: `==` проверяет, что две ссылки указывают на один объект; `!=` — что на разные.

### 5.6. Логические операции

Для типа `bool` поддерживаются следующие операции:

- `&&` — логическое И;
- `||` — логическое ИЛИ;
- `!` — логическое НЕ.

Операции `&&` и `||` принимают два логических значения и возвращают логическое значение.

Операция `!` принимает одно логическое значение и возвращает противоположное.

Операторы `&&` и `||` используют вычисление по короткой схеме: правый операнд не вычисляется, если результат уже определяется левым операндом.

### 5.7. Приоритет операций

Операции имеют следующий приоритет от высшего к низшему:

1. Скобки `()`, доступ к элементу `[]`, доступ к полю `.`.
2. Унарные операции `-`, `!`.
3. Умножение, деление и остаток от деления `*`, `/`, `%`.
4. Сложение и вычитание `+`, `-`.
5. Операции сравнения `<`, `>`, `<=`, `>=`.
6. Операции равенства `==`, `!=`.
7. Логическое И `&&`.
8. Логическое ИЛИ `||`.

Бинарные операции одного уровня приоритета являются левоассоциативными.

Скобки позволяют явно изменять порядок вычисления выражений.

### 5.8. Переменные и области видимости

1. Область видимости переменной определяется блоком кода, в котором она объявлена.
2. Переменная доступна после объявления и до завершения соответствующего блока.
3. Переменная должна быть инициализирована непосредственно при объявлении.
4. Использование переменной до её объявления запрещено.
5. Переменные, объявленные внутри блока, недоступны за его пределами.
6. Вложенный блок может обращаться к переменным внешнего блока.
7. Повторное объявление переменной с тем же именем в одной области видимости запрещено.

### 5.9. Инструкции

1. Инструкция `if` выполняет блок кода, если условие имеет значение `true`.
2. Если условие `if` имеет значение `false`, выполняется блок `else`, если он присутствует.
3. Условие конструкции `if` должно иметь тип `bool`.
4. Инструкция `while` выполняет блок кода до тех пор, пока условие имеет значение `true`.
5. Условие цикла `while` должно иметь тип `bool`.
6. При вложенных конструкциях `if` ветка `else` относится к ближайшему предшествующему `if`, для которого ещё не определена ветка `else`.

### 5.10. Массивы

1. Массив — ссылочный тип фиксированной длины.
2. Длина массива задаётся при создании: `new T[n]`, где `n` — выражение типа `int`, `n >= 0`.
3. Все элементы нового массива инициализированы нулевыми значениями типа `T`:
    - `0` для `int`;
    - `0.0` для `float`;
    - `""` для `string`;
    - `false` для `bool`;
    - нулевая ссылка для массива структур (см. п. 5.11).
4. Доступ к элементу: `arr[i]`, где `0 <= i < len(arr)`. Доступ по индексу вне диапазона — ошибка выполнения.
5. Длина массива доступна через поле `length`: `arr.length` имеет тип `int`.
6. Присваивание массива меняет ссылку, не копируя массив.
7. Литерал массива `{e1, e2, ..., en}` создаёт массив длины `n`; тип элементов выводится из контекста (левая часть объявления или присваивания). Пустой литерал `{}` создаёт массив длины 0.
8. Массив структур `S[]` хранит ссылки на структуры; элементы по умолчанию равны нулевой ссылке.

Пример:

```go
int[] scores = new int[10];
scores[0] = 100;
print(scores[0]);
print(scores.length);   // 10

string[] names = {"Alice", "Bob"};
print(names.length);    // 2
```

### 5.11. Структуры

1. Структура — ссылочный тип, объявляемый на верхнем уровне программы.
2. Структура содержит именованные поля; каждое поле имеет тип.
3. Имена полей в пределах одной структуры должны быть уникальны.
4. Порядок полей в объявлении определяет порядок в литерале структуры.
5. Литерал структуры `S{e1, e2, ..., en}` создаёт экземпляр структуры `S`, где `ei` присваивается `i`-му полю. Число элементов должно совпадать с числом полей, типы — соответствовать типам полей.
6. Доступ к полю: `s.f` — чтение, `s.f = expr;` — запись.
7. Присваивание структуры меняет ссылку, не копируя структуру.
8. Доступ к полю через нулевую ссылку (например, неинициализированный элемент массива структур) — ошибка выполнения.
9. Структуры не поддерживают наследование, методы и инкапсуляцию.

Пример:

```go
struct Point {
    int x;
    int y;
}

Point p = Point{1, 2};
print(p.x);     // 1
p.y = 10;
print(p.y);     // 10

Point[] path = new Point[3];
path[0] = Point{0, 0};
print(path[0].x);   // 0
```

### 5.12. Встроенные функции

В текущей версии языка предусмотрена встроенная функция:

`print(expression)`

1. Функция выводит значение переданного выражения в стандартный поток вывода.
2. После вывода значения автоматически добавляется перевод строки.
3. Функция поддерживает значения типов `int`, `float`, `string` и `bool`.
4. Функция не возвращает значение.

## 6. Завершение программы и обработка ошибок

1. Выполнение программы начинается с функции `main`.
2. После завершения выполнения всех инструкций функции `main` программа завершается с нулевым кодом возврата.
3. Ошибки лексического анализа приводят к прекращению обработки программы.
4. Синтаксические ошибки приводят к прекращению разбора программы.
5. Ошибки выполнения, включая деление на ноль, приводят к аварийному завершению программы.
6. Сообщения об ошибках выводятся в стандартный поток ошибок `stderr`.
7. При возникновении ошибки программа должна завершиться с ненулевым кодом возврата.
