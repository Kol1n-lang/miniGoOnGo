# Список тестов лексера miniGoOnGo

- [x] Разбор идентификаторов
- [x] Разбор идентификаторов, начинающихся с подчёркивания
- [x] Разбор идентификаторов с подчёркиванием в середине
- [x] Регистр имеет значение: `Name` — идентификатор, не ключевое слово
- [x] Кириллица не является допустимым символом идентификатора
- [x] Разбор целочисленных литералов
- [x] Разбор вещественных литералов
- [x] Ведущий ноль в целочисленном литерале — ошибка
- [x] Ведущий ноль в вещественном литерале — ошибка
- [x] Точка без цифры после — не часть числа, а отдельный токен `Dot`
- [x] Литерал `int`, не помещающийся в разрядность `int32`, — ошибка
- [x] Знак минус — оператор, а не часть литерала
- [x] Разбор булевых литералов
- [x] Разбор строковых литералов
- [x] Пустая строка
- [x] Строка с escape-последовательностями (`\"`, `\\`, `\n`, `\t`, `\r`)
- [x] Кириллица в строке (UTF-8)
- [x] Реальный перенос строки внутри литерала — ошибка
- [x] Незакрытая строка — ошибка
- [x] Неизвестная escape-последовательность — ошибка
- [x] Токен содержит значение идентификатора
- [x] Токен содержит значение целочисленного литерала
- [x] Токен содержит значение вещественного литерала
- [x] Токен содержит значение строкового литерала
- [x] Разбор циклов и ветвлений (`if` / `else` / `while`)
- [x] Разбор объявлений переменных всех базовых типов (`int`, `float`, `string`, `bool`)
- [x] Разбор операторов сравнения (`==`, `!=`, `<`, `<=`, `>`, `>=`)
- [x] Разбор арифметических операторов (`+`, `-`, `*`, `/`, `%`)
- [x] Разбор логических операторов (`&&`, `||`, `!`)
- [x] Одиночные `&` и `|` — ошибка (не операторы языка)
- [x] Разбор скобок и разделителей (`()`, `{}`, `;`, `,`)
- [x] Разбор объявления функции `main`
- [x] Разбор встроенной функции `print`
- [x] Разбор квадратных скобок `[` и `]`
- [x] Разбор создания массива (`new int[10]`)
- [x] Разбор объявления массива (`int[] arr = new int[5];`)
- [x] Разбор индексации (`arr[0]`)
- [x] Разбор поля `length` (`arr.length`)
- [x] Разбор литерала массива (`{1, 2, 3}`)
- [x] Разбор пустого литерала массива (`{}`)
- [x] Разбор объявления структуры (`struct Point { ... }`)
- [x] Разбор литерала структуры (`Point{1, 2}`)
- [x] Разбор доступа к полю структуры (`p.x`)
- [x] Разбор записи в поле структуры (`p.y = 10;`)
- [x] Разбор массива структур (`Point[] path = new Point[3];`)
- [x] Разбор цепочки `arr[i].field` (`path[0].x`)
- [x] Разбор однострочных комментариев (`//`)
- [x] Многострочные комментарии не поддерживаются (`/*` — это `Divide` + `Multiply`)
- [x] Пробельные символы пропускаются (SP, HT, LF, CR)
- [x] Переносы строк пропускаются (CRLF, LF, CR эквивалентны)
- [x] Табуляция учитывается при подсчёте колонки (ширина 4)
- [x] Только пробельные символы — пустой поток токенов
- [x] Пустой исходник — пустой поток токенов
- [x] `Token.String()` форматирует токен для отладки
- [x] Сканер: `peek`, `peekN`, `advance`, обновление `Line`/`Column`
- [x] Сканер: корректная обработка конца файла
- [x] Разбор нулевого литерала (`nil`)
- [x] Сравнение ссылки с `nil`
